# Installing mgi-mind

Installation instructions for AI agents are in
[AI_INSTRUCTIONS.md](AI_INSTRUCTIONS.md), in its "Installing mgi-mind" section
(near the top of that file, before "The one rule").

Read that section and follow it in order: decide the install target, install,
verify, wire it into your client, then load the behaviour protocol from the
rest of AI_INSTRUCTIONS.md into the client's own rules file.
